INTERACTIVE FIRST ANNIVERSARY WEBSITE

HOW TO RUN
1. Extract this ZIP.
2. Open index.html in a browser (double-click it).
3. Add your photos in the images folder using these filenames:
   cover.jpg
   memory-1.jpg
   memory-2.jpg
   memory-3.jpg
   memory-4.jpg

PERSONALIZE IT
- Open index.html in VS Code.
- Change the timeline titles and the data-message text on each timeline-card.
- Replace the sample love letter inside the letter-paper section.
- Update the anniversary date (currently shown as 19 · 11 · 2026).
- Replace the captions and surprise message with your own words.
- Change colours and layout in style.css.

NOTES
- No framework or installation is needed.
- Google Fonts requires an internet connection; fallback fonts will still work offline.
- Replace photo filenames in index.html if you use PNG or WEBP.
